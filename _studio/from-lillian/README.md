# From Lillian

This is where Lillian can upload sketches, references, pixel-art experiments, notes and other creative responses to the handoffs in To Lillian.

A response can be unfinished. It does not need to be technically perfect.

After review, Sean will either:

- incorporate it into the game;
- ask for another iteration;
- move it to the archive;
- or keep it as a reference or experiment.

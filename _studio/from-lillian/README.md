# From Lillian

This is where Lillian can upload sketches, references, pixel-art experiments, notes and other creative responses to the handoffs in To Lillian.

A response can be unfinished. It does not need to be technically perfect.

After review, Sean will either:

- incorporate it into the game;
- ask for another iteration;
- move it to the archive;
- or keep it as a reference or experiment.

## Target pixel dimensions

When a piece is meant to land at final size, match the current role dimensions (also in `../to-lillian/README.md`):

| Role | Dimensions | Notes |
| --- | --- | --- |
| Portrait | 48×48 | Just adjusted from 40×40 — use 48×48 for all new portrait work. |
| Battle | 32×32 | Unchanged. |
| Overworld | 16×20 (north/south) or 20×16 (east/west) | Quadruped; width and height flip depending on facing. |

The current shared master palette is `../to-lillian/cooper-and-mango-master-palette.aseprite`.

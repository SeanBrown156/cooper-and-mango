# To Lillian

This folder contains creative handoffs from Sean to Lillian.

Each handoff should have its own folder with a short HANDOFF.md explaining:

- what we are making;
- what the references show;
- what Lillian is being asked to explore;
- what questions need answering;
- where to upload the response.

When a handoff is active, it belongs here. When it is finished, move it to the archive.

# Cooper & Mango Studio

Welcome to the shared creative workspace for Cooper & Mango.

This is the place for Sean and Lillian to exchange references, briefs, sketches, asset experiments and creative ideas.

You do not need to understand the rest of the repository to use this folder.

## Where things go

- [To Lillian](to-lillian/) — references, briefs and creative tasks Sean has prepared.
- [From Lillian](from-lillian/) — sketches, ideas and assets Lillian has sent back.
- [Archive](archive/) — completed handoffs and past creative exchanges.

## The basic flow

1. Sean prepares a creative handoff in To Lillian.
2. Lillian reviews the references and works on the idea.
3. Lillian uploads the result into From Lillian.
4. Sean reviews it and moves approved work into the official game folders.
5. The completed exchange is moved into Archive.

Anything in this folder is part of the creative working process. It is not automatically an approved game asset or final design decision.

## Tools and what they are for

Lillian does not need to use every tool in the project. The most important creative tools are:

- **GitHub** — the shared home for the project. Use the browser to read handoffs, view references and upload work.
- **FigJam** — the inspiration and mood-boarding space. Use it for visual references, game examples, palettes, room inspiration, screenshots and loose creative exploration.
- **Pixquare** — the main iPad and Apple Pencil pixel-art tool for drawing, adjusting, cleaning up and animating sprites.
- **Procreate** — useful for loose sketches, character ideas, poses, room concepts and visual problem-solving.
- **PixelLab** — the AI pixel-art generation and variation tool. It is useful for exploring character, prop, environment, tile and animation directions from strong references.
- **Aseprite** — the desktop pixel-art production tool for precise cleanup, palettes, animation timing, sprite sheets and canonical editable masters.
- **Godot** — the game engine. Sean uses it to assemble assets into rooms and scenes and to test how they feel in the running game.
- **Real photos** — the likeness and physical reference for Mango, Cooper, the home, furniture and important objects.
- **Gemini / ChatGPT** — optional tools for visual ideation, comparison, critique and early concept exploration.

### Lillian's main creative workflow

For Lillian, the usual path is:

1. Look at the references in a handoff or FigJam.
2. Open the working asset in Pixquare on the iPad.
3. Draw, adjust or animate the idea.
4. Upload the result through the GitHub browser into From Lillian.
5. Add a short note explaining what it is or what feedback is wanted.

### Sean's production tools

Sean may also use these tools behind the scenes:

- **Claude Code / Codex** — code, structured data, repetitive integration and project maintenance.
- **Ableton** — music composition and audio production.
- **JSFXR and other audio tools** — exploratory 8-bit sound and music experiments.
- **Supabase** — a possible future structured content-authoring layer, once the content schema is proven.

The tools may change over time. The creative roles remain stable: gather references, explore, make, review, approve and integrate.

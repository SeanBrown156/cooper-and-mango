# Mango east Sora motion reference

Generated from the clean east-facing Mango sprite as a motion study. The
prompt required a locked side-view, right-facing, four-legged orange cat with
alternating paw plants and no clothing or hoodie.

- Sora job: `video_6a86ac0f325881919b2b92488c2244fa0dd8800f741f52ec`
- Source video: `mango_east_walk_sora.mp4`
- Extracted frames: `mango-overworld-east-sora-frame-1.png` through `-8.png`
- Frame size: `20x16` RGBA
- Reference image: `mango_east_reference_1280x720.png`

The eight frames are fixed-window nearest-neighbour reductions from evenly
spaced samples. They are intended as leg-motion reference/cleanup material,
not as a final pixel-faithful replacement for the hand-authored sprite.

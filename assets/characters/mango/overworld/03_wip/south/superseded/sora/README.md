# Sora motion-reference experiment

This folder is reserved for a Sora 2 motion-reference clip and extracted
frames. Sora is being used as motion reference only; the final sprite must be
cropped, normalized and reviewed back to the native 16×20 canvas.

The completed job is `video_6a869a82ff6c8191a8c911e4727a40310b20a5a61d078837`.
The clip has been downloaded as `mango_south_walk_sora.mp4` and sampled at 4
fps under `frames_reference/`. It is useful for studying explicit leg timing,
but it drifts from Mango's tiny quadruped grammar, so it is not a promotion
candidate as-is.
